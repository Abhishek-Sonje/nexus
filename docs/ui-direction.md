# Nexus UI direction

## Signal Observatory

Nexus behaves like a geological monitoring room: stable instruments reveal where a payment network stops behaving normally. The interface is dark, measured, and evidence-led rather than theatrical.

- **Mode:** Operate.
- **Structure:** metrics-first; evaluation verdict and economics precede findings and graph evidence.
- **Palette:** charcoal instrument fields, cool mineral text, warm amber for review, and muted vermilion for elevated risk.
- **Material:** calibrated rules, fixed columns, sparse signal lamps, and dense evidence surfaces.
- **Typography:** a workhorse proportional interface face with tabular numerals; monospace is reserved for identifiers and measurements.
- **Signature interaction:** selecting a ranked disturbance focuses the same entity across the score explanation, evidence register, and bounded relationship graph.
- **Responsive rule:** desktop carries the full instrument field; mobile preserves metrics and evidence while replacing the dense graph with a textual relationship summary.

### Raised disciplines

- From split-flap concourse boards: columns remain fixed so metric and finding changes are instantly comparable.
- From cyclorama cue systems: risk intensity is expressed in named bands, with text and pattern carrying every meaning that color carries.

### Honest risk

Without precise calibration detail and evidence hierarchy this world could collapse into a generic dark operations console. The implementation must prove the network mechanism in the first viewport and avoid neon, glow, decorative glass, and fake terminal styling.

### Direction contract

- **THESIS:** risk is a measured disturbance, and the dashboard refuses the generic card-grid fraud console.
- **OWN-WORLD:** charcoal calibrated fields, mineral text, amber review signals, vermilion risk signals, fixed data columns, and engraved rules.
- **STORY:** understand held-out performance and cost, identify the most material disturbance, then trace its score back to network evidence.
- **FIRST VIEWPORT:** a compact navigation rail frames a broad held-out verdict, an economic cost curve, and immutable run provenance; ranked findings begin before the fold.
- **FORM:** Signal Observatory, assigned direction five, seed `171a808a`.
- **FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
