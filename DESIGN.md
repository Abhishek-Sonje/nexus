# Nexus design record

## Product expression

The shipped interface follows the **Signal Observatory** direction: fraud-network risk is treated as a measured disturbance rather than a theatrical cybersecurity event. Dark charcoal instrument fields, mineral text, calibrated rules, and restrained amber/vermilion signals create a dense investigation surface without glow, glass, or fake terminal styling.

The primary reading order is fixed:

1. synthetic held-out status and evaluation verdict;
2. economic and precision-recall operating point;
3. immutable dataset, detector, and run provenance;
4. ranked suspicious communities;
5. deterministic score components and bounded relationship evidence.

## Information and interaction

The dashboard uses stable columns and tabular numerals so investigators can compare measurements without layout shift. Risk is always named and quantified; color is supplementary. URLs own run/finding state, while local component state is limited to graph interaction.

Sigma is lazy-loaded on the client and initialized only after its container has measurable dimensions. The graph is bounded to the selected finding and capped evidence set, then disposed during navigation. The adjacent relationship register is the semantic, keyboard-accessible alternative and remains available when the graph is hidden.

Desktop is the primary surface. Tablet layouts reflow the metric and evidence regions. Mobile retains verdicts, findings, and the focusable relationship table while suppressing the dense graph. Reduced-motion preferences disable nonessential smooth behavior.

## Accessibility finish

- Visible keyboard focus is applied globally.
- Ranked findings and relationship evidence expose table, row, column-header, and cell semantics.
- Scrollable evidence regions are keyboard focusable.
- Muted text was calibrated above WCAG AA contrast against the dark surfaces.
- Automated Axe checks cover both desktop Chromium and a mobile viewport.

## Tokens

The project-owned CSS tokens in `apps/web/src/app/globals.css` define charcoal surfaces, rule strengths, mineral text levels, semantic risk colors, focus color, and the proportional/monospace typography roles. Components use these tokens rather than a generic dashboard kit.

## Boundaries

The interface makes synthetic provenance visible and avoids production-accuracy language. Gemini narrative is visually subordinate to deterministic evidence. There are no controls for payment action, case disposition, assignment, or other workflows outside the read-only MVP.
